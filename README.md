# AI-Based Multilingual Mass Communication & Public Awareness Management Platform

A production-grade multilingual mass communication system featuring:
- **Frontend**: React + Vite + TailwindCSS modern citizen messaging hub
- **Backend API**: Django REST Framework + SimpleJWT
- **AI Microservice**: FastAPI + Groq (Llama/GPT-OSS) + IndicTrans2 Multilingual Translation Engine
- **Vercel Config**: Pre-configured multi-service microservice deployment (`vercel.json`)
